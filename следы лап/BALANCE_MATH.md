## 2. Физика выгула и тайминги захвата

### 2.1. Кинематика прогулки:
* **Средняя скорость прогулки с собакой ($V_{avg}$):** $4.2\text{ км/ч} \approx 1.17\text{ м/с}$.
* **Диапазон допустимых скоростей:**
  * $V_{min} = 1.5\text{ км/ч}$ ($0.42\text{ м/с}$) — медленный шаг с остановками на обнюхивание.
  * $V_{max} = 12.0\text{ км/ч}$ ($3.33\text{ м/с}$) — бег трусцой с собакой (каникросс).
  * $V_{cutoff} = 18.0\text{ км/ч}$ — порог отсечки (велосипед, самокат, авто).

### 2.2. Время прохождения одной ячейки:
* Проход по диаметру соты ($114\text{ м}$):
  $$\tau = \frac{114\text{ м}}{1.17\text{ м/с}} \approx 97\text{ секунд} \approx 1.6\text{ минуты}$$
* **Условие валидации взятия ячейки (Анти-дребезг GPS):**
  * Игрок должен пройти внутри соты кумулятивную дистанцию:
    $$S_{inside} \ge 40\text{ метров}$$
  * Либо провести внутри соты время:
    $$t_{inside} \ge 45\text{ секунд (при скорости } > 0.5\text{ м/с)}$$
  * Это исключает случайный захват соседней соты при погрешности GPS на границе.

## 3. Математика Очков Запаха (Scent Points) и Затухания (Decay)

### 3.1. Шкала влияния:
* **$SP \in [0, 300]$**
* Порог владения: $SP \ge 50$.
* Полноценный захват: $SP = 100$.
* Максимальная броня (фортификация): $SP = 300$.

### 3.2. Начисление очков при визите:
$$\Delta SP = 100 \times M_{pack} \times M_{fraction}$$
где:
* $M_{pack}$ — мультипликатор стаи ($1.0$ при соло, $1.5$ при прогулке вдвоем, $2.0$ при группе $\ge 3$ собак).
* $M_{fraction}$ — классовый модификатор фракции (например, $1.15$ у «Лиги Спринтеров»).

### 3.3. Модель выветривания запаха (Daily Decay):
Каждые сутки в 04:00 по местному времени происходит пересчет:
$$SP_{t+1} = \max\left(0, \lfloor SP_t \times 0.67 \rfloor\right)$$

#### График затухания без повторного выгула:

## 4. Алгоритм «Замыкание контура» (Loop Enclosure Math)

```
Шаги алгоритма:
1. Фиксация трека прогулки как последовательности точек P = [(lat_0, lon_0), ..., (lat_n, lon_n)].
2. Проверка расстояния старт-финиш: Dist(P_0, P_n) <= 50 метров.
3. Проверка минимальной длины трека: Length(P) >= 300 метров.
4. Построение замкнутого полигона Poly = Polygon(P).
5. Нахождение внутренних гексагонов:
   Cells_enclosed = h3.polygonToCells(Poly, resolution=10) \ Cells_perimeter
6. Валидация ограничения:
   len(Cells_enclosed) <= MAX_ENCLOSED_CELLS (19 штук)
```

### Награды за замыкание контура:
* Каждая внутренняя ячейка получает:
  $$SP_{bonus} = +100\text{ SP}$$
* Игрок получает мгновенный бонус:
  $$Bones_{bonus} = 25 \times \text{Количество захваченных ячеек}$$

## 5. Экономический баланс «Сахарных косточек»

### 5.1. Дневной баланс среднего игрока:
* **Прогулки в день:** 2 прогулки.
* **Средняя дистанция в день:** $3.5\text{ км}$.
* **Гексагонов пройдено:** $10–14$ ячеек.
* **Дневной доход:**
  * За километраж: $3.5 \times 10 = 35$ косточек.
  * За взятие/обновление гексагонов: $12 \times 5 = 60$ косточек.
  * За замыкание 1 контура: $+25$ косточек.
  * **Итого в день:** $\approx 120$ косточек.
  * **Итого в неделю:** $\approx 840$ косточек.
