# 🗺️ Дорожная карта разработки MVP (Web + Mobile + Симуляторы)

---

## 1. Приоритизация функций (Методология MoSCoW)

### 🔴 Must Have (Критично для запуска MVP и локального тестирования)
1. **Кроссплатформенное ядро (React + Vite + Leaflet + H3-js):**
   * Мгновенный локальный запуск в браузере на ПК (`localhost:5173`) и на мобильном телефоне по Wi-Fi сети.
2. **Интерактивная карта Uber H3 Res 10:**
   * Отображение гексагональной сетки, закрашивание сот цветами фракций, статус прочности (SP).
3. **Модуль симуляции перемещения (Sandbox Dev Tools):**
   * Экранный виртуальный тач-джойстик для мобильных браузеров.
   * Управление клавишами WASD / стрелками на ПК и перемещение по клику на карте.
   * Переключатель между реальным GPS (`navigator.geolocation`) и симулятором.
4. **Движок симуляции ботов-соседей (AI Neighborhood Engine):**
   * Генерация 5–10 виртуальных собак (Корги, Стаффы, Хаски) с разными фракциями и поводками.
   * Боты автономно патрулируют свои дворы, захватывают нейтральные соты и реагируют на прогулку игрока.
5. **Механика захвата и «Замыкание контура» (Loop Enclosure):**
   * Автоматический захват внутренних сот при обходе квартала по кругу.
   * Тестовая кнопка «Обойти квартал» для мгновенной проверки замыкания.
6. **Слой безопасности Crowd-Safety:**
   * Метки «Отрава», «Стекло», «Реагенты», карточки с подтверждениями соседей, кнопка спавна тестовой угрозы.
7. **Конфигурация Capacitor для Android:**
   * Настройка нативной обертки для сборки установочного **Android APK** для проверки на физическом смартфоне на улице.

---

### 🟡 Should Have (2-я волна)
1. Экстренный экран SOS «Потерялась собака» с зоной поиска на карте.
2. Суточное затухание (Decay) и кнопка ускоренной перемотки времени (+24 часа).
3. Лидерборд района («Топ собак ЖК»).
4. Интеграция фонового Capacitor Background Geolocation для сборки APK.

---

### 🟢 Could Have (Пост-MVP)
1. PWA Service Worker (оффлайн кэширование тайлов карты).
2. Магазин кастомизации за «Сахарные косточки» (скины следов лапок).
3. Сборка десктопного приложения через Tauri / Electron.
