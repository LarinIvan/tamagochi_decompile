# 🐾 След Лапы (Квартал Наш)
> **Гео-стратегия захвата районов и краудсорсинговый радар безопасности для собаководов**

---

## 🚀 Быстрый запуск

### 1. Тестирование в браузере (ПК и смартфон):
1. Запустите файл **`ЗАПУСК_ВЕБ.bat`** (или выполните в терминале `cd client && npm run dev`).
2. **На ПК:** откройте ссылку [http://localhost:5173](http://localhost:5173).
3. **На смартфоне в браузере:** подключитесь к тому же Wi-Fi и откройте локальный адрес (например, `http://192.168.x.x:5173`), который отобразит Vite.

### 2. Сборка Android APK для физического телефона:
1. Запустите скрипт **`СБОРКА_APK.bat`**.
2. Готовый файл появится по пути:
   `следы лап/client/android/app/build/outputs/apk/debug/app-debug.apk`.

## 🌟 Ключевые возможности проекта

### 🗺️ Мульти-картографический движок (100% бесплатно)
Мгновенное переключение картографических слоев через кнопку слоев в правом верхнем углу:
* **2GIS:** подробная городская карта с домами и проездами.
* **Яндекс.Карты:** народная схема с адресными табличками.
* **Google Maps (Схема) и Google Спутник:** детализированная аэрофотосъемка парков и дворов.
* **OpenStreetMap (OSM):** глобальный открытый картографический стандарт.
* **CartoDB Dark Matter:** неоновый контрастный ночной стиль, на котором соты выглядят эффектнее всего.

### 🎮 Гео-стратегия на Uber H3 (Resolution 10)
* Сетка гексагонов (~100 метров в поперечнике) покрывает весь город.
* **Захват сот:** проход через соту начисляет очки запаха (SP) вашей фракции:
  * 🔵 **«Лига Спринтеров»** (Корги, Шпицы, Таксы)
  * 🔴 **«Орден Стражей»** (Овчарки, Стаффы, Ротвейлеры)
  * 🟡 **«Братство Вольных»** (Хаски, Метисы, Лабрадоры)
* **Замыкание контура (Loop Enclosure):** если вы обходите квартал по кругу и замыкаете периметр, **все внутренние соты захватываются автоматически** со статусом «Закрытый двор» (+100 SP к защите)!
* **Затухание (Decay):** соты теряют 33% запаха в сутки, стимулируя регулярный утренний и вечерний выгул.

### 🕹️ Встроенная песочница тестирования (Dev Sandbox)
Вам не нужно мерзнуть на улице, чтобы протестировать механику:
* **Экранный сенсорный джойстик:** для управления перемещением на телефоне.
* **Управление WASD и стрелками на ПК:** быстрое перемещение по улицам.
* **Клик по карте («Идти сюда»):** собака плавно идет к указанной точке.
* **Кнопка «🔄 Обойти квартал»:** запускает автоматический обход периметра двора для моментальной проверки алгоритма замыкания контура.
* **Кнопка «⏳ Промотать 24 часа»:** симулирует выветривание запаха.

### 🤖 Движок симуляции ботов двора (AI Neighborhood Engine)
* В районе живут и гуляют виртуальные собаки соседей: «Барон» (Ротвейлер), «Скай» (Хаски), «Майя» (Джек-рассел), «Арчи» (Ретривер), «Бусинка» (Шпиц).
* Боты автономно патрулируют дворы, красят соты в свои цвета, отображаются на живом радаре и ставят метки.
* Клик по любой собаке на карте открывает ее **карточку с фото, породой, повадками** и кнопкой «Помахать лапой» 🐾.

### 🐕 Обширная система профилей и мульти-пет поддержка
* **Профиль хозяина:** имя, никнейм, карма надежности, район/ЖК, график выгула.
* **Мульти-профиль собак:** можно добавить сколько угодно своих собак.
* **Настройки питомца:** кличка, порода из каталога, пол, возраст, вес, повадки (теги), выбор уникальной иконки на карте (лапка, мордочка корги, овчарки, корона, косточка, огонь).
* **Цветовой код поводка:**
  * 🟢 **Зеленый:** «Ищем друзей для игр»
  * 🟡 **Желтый:** «На поводке / держим дистанцию»
  * 🔴 **Красный:** «Осторожно, не подходить (реактивный / течка)»
  * 👻 **Стелс:** «Режим невидимки»

### 🛡️ Слой безопасности (Crowd-Safety) и SOS
* Метки угроз: ☠️ Отрава / Догхантеры, 🧪 Реагенты, 🍾 Битое стекло, 🕳️ Открытые люки, 🐕‍🦺 Агрессивная стая.
* **Аудио-сирена и вибро-предупреждение в кармане** при приближении к опасности на 50 метров!
* **Кнопка экстренного SOS:** мгновенный шторм-пуш всем собачникам в радиусе 1.5 км с фото и контактами потерявшейся собаки.
